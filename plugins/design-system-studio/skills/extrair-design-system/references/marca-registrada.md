# Marca registrada e uso como referência

- O design system extraído é **referência**. Logo, nome, fontes pagas, imagens e textos pertencem ao dono do site.
- **Site da própria pessoa:** use à vontade; a extração só organiza o que já é dela.
- **Site de terceiro:** serve para estudar padrões (escala, contraste, espaçamento). Não publique o logo, as imagens nem um layout que se confunda com a marca. Fontes do Google Fonts têm licença aberta; fontes de `@font-face` próprias podem ser pagas: confira a licença antes de usar.
- **Proposta para um cliente:** a extração do site atual do cliente pode entrar na proposta, com a fonte e a data que o `DESIGN.md` já registra.
- Na dúvida, pergunte à pessoa e registre a decisão no `DESIGN.md`.
